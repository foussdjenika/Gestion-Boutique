Comment commencer ?

1

Téléchargez et Installez

Cliquez sur le bouton "Télécharger" pour obtenir le fichier APK. Ouvrez-le et autorisez l'installation.

2

Créez votre compte Admin

Ouvrez l'application. Cliquez sur "Créer un compte Admin". Remplissez le formulaire (Nom, Email, Mot de passe). Internet requis.

3

Demandez l'activation

Vous verrez un écran d'attente. Cliquez sur le bouton vert "Activer via WhatsApp". Votre compte sera validé après paiement.
